## What to name

A monocyclic ring (already in T3's heterocycle table, or carbocycle) where a RING carbon has an exocyclic `=O`:
- **Saturated lactam** (ring N adjacent to ring C=O): `pyrrolidin-2-one`, `piperidin-2-one`, `azepan-2-one` (caprolactam), `azetidin-2-one`. No indicated H.
- **Saturated lactone** (ring O adjacent to ring C=O): `oxolan-2-one` (γ-butyrolactone), `oxan-2-one`, `oxetan-2-one`. No indicated H.
- **Carbocyclic ring ketone** already works in T3 (cyclohexanone) — don't regress.
- **Aromatic/mancude ring carbonyl** (needs INDICATED HYDROGEN): `pyridin-2(1H)-one`, `pyridin-4(1H)-one`, `2H-pyran-2-one`, `4H-pyran-4-one`, `pyrimidine-2,4(1H,3H)-dione` (uracil), `pyrimidin-2(1H)-one`. Harder — attempt, but DECLINE any whose name doesn't OPSIN-round-trip to the input.

## Approach

1. **Perception:** detect ring carbon(s) with exocyclic `=O`. Classify the ring (via T3's ring tables/fingerprint) as carbocycle vs the tabled heterocycle. Distinguish saturated (no ring double bonds besides the C=O) from mancude/aromatic (needs indicated H).
2. **Saturated heterocyclic carbonyl → lactam/lactone:** parent = saturated heterocycle name (pyrrolidine/piperidine/azepane/azetidine/oxolane/oxane/oxetane…); add `-one` at the carbonyl ring locant (number so heteroatom=1, carbonyl gets lowest locant → almost always `-2-one`). 'e'-elision (oxolane→oxolan-2-one).
3. **Aromatic/mancude ring carbonyl → indicated hydrogen:** parent = aromatic heterocycle (pyridine/pyran/pyrimidine…); the ring loses aromaticity at the carbonyl, so cite added/indicated hydrogen: `pyridin-2(1H)-one`. Compute the indicated-H locant (the saturated ring position — typically the ring N for pyridinone). Multiple carbonyls → `-dione` with both indicated Hs (uracil → `pyrimidine-2,4(1H,3H)-dione`). If you cannot compute the indicated H so the name OPSIN-round-trips, DECLINE.
4. Substituents/other functional groups on the ring handled as in T3. Completeness + no-wrong-names guards enforced.
