## Algorithm (monospiro)

A monospiro system = two rings sharing exactly ONE atom (the spiro atom). Ring sizes give the descriptor: `spiro[a.b]<stem>ane`, where a≤b are the atom counts in each ring EXCLUDING the spiro atom (smaller first), and stem = chain stem for total ring atoms (a+b+1).
- e.g. spiro[4.5]decane (a=4, b=5, total 10); spiro[3.3]heptane; spiro[2.2]pentane.
- **Numbering:** start at the ring atom NEXT TO the spiro atom in the SMALLER ring, number around the smaller ring back to the spiro atom (spiro atom gets the next number = a+1), then continue around the larger ring. Choose start/direction for lowest locants to (heteroatoms > PCG > substituents).
- **Heteroatoms** → replacement prefixes with locants (e.g. `1-oxaspiro[4.5]decane`, `1,4-dioxaspiro[4.5]decane` — common ketal). Lowest locants to heteroatoms.
- **Substituents/unsaturation/functional groups** numbered per the spiro numbering.

Dispiro/polyspiro (≥2 spiro atoms) → DECLINE (later).
