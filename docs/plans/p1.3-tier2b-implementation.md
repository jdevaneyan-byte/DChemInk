(anhydride 75, ester 70, acylHalide 65 — all below acid 80, above amide 60).
Replace the three `unsupported` early-returns (acyl halide, ester, and keep the
carbonic-acid-derivative + charged checks) with real `groups.push(...)`.

Group records:
- **acylHalide**: `{ kind, carbon: acylC, atoms: [=O, halogen], detail: halogenElement }`.
- **ester**: `{ kind, carbon: acylC, atoms: [=O, bridgingO] }`; the O-alkyl carbons stay in the graph (named separately by the engine).
- **anhydride**: detect an O single-bonded to TWO carbonyl carbons. `{ kind, carbon: acylC1, atoms: [bridgingO, =O(1), =O(2)], detail: secondAcylC }` (record the second acyl carbon so the engine can name both sides).

## Task 2: Two-part name builders (`assemble.ts`)

Add exported builders that compose a parent stem (+ optional unsaturation from
the existing `ending`-style logic) with class endings. Reuse the existing parent
machinery; only the endings/words are new.

```ts
// acyl group: acid parent with "-oyl" (e-elision before the 'o').
//   ethanoyl, propanoyl, prop-2-enoyl
export function acylName(chainLen: number, doubles: number[], triples: number[], subs: Sub[]): string;
// "<acyl> <halide-word>"  → "ethanoyl chloride"
export function acylHalideName(acyl: string, halogen: string): string; // F→fluoride, Cl→chloride, …
// "<R'-yl> <acid-stem>oate"  → "ethyl ethanoate"
export function esterName(alkyl: string, acidChainLen: number, doubles: number[], triples: number[], subs: Sub[]): string;
// symmetric: "<stem>oic anhydride"; mixed: "<a>oic <b>oic anhydride" (alphabetical)
export function anhydrideName(side1: string, side2: string): string; // each side = "ethanoic", "propanoic", …
```

(`Sub = { locant: number; name: string }`.) The acid/acyl chain is numbered with
the carbonyl carbon as C1; unsaturation/substituents on it are expressed via the
existing assembly pieces. 'e'-elision: drop the parent terminal 'e' before
`-oyl`/`-oate`/`-oic` (all start with 'o').

- [ ] **Step 1: Failing tests** (assert exact strings, PubChem-checked):
  acylHalideName(ethanoyl, "Cl")→"ethanoyl chloride"; esterName("ethyl", 2,…)→"ethyl ethanoate"; esterName("methyl",3,…)→"methyl propanoate"; anhydrideName("ethanoic","ethanoic")→"ethanoic anhydride"; anhydrideName("ethanoic","propanoic")→"ethanoic propanoic anhydride"; acyl with unsaturation → "prop-2-enoyl chloride", "prop-2-enoate".
- [ ] **Step 2–4:** TDD implement + pass.

## Task 3: Engine routing + completeness (`engine.ts`)

When `principalKind` is `acylHalide`/`ester`/`anhydride`, branch to a dedicated
path BEFORE the normal suffix path:

- **acyl halide**: parent chain = the acyl carbon's chain (carbonyl C is terminal/C1). Build acyl name via `acylName` (with that chain's unsaturation + alkyl subs + any lower-priority FG prefixes), then `acylHalideName`. Halogen from `detail`.
- **ester**: acyl side chain (carbonyl C1) → acid stem; O-alkyl side = the carbons reachable from the bridging O on the non-acyl side → name with `nameSubstituent` to get `methyl`/`ethyl`/`propan-2-yl`. `esterName(alkyl, acidChainLen, …)`.
- **anhydride**: two acyl sides (the two carbonyl carbons from `carbon` + `detail`); name each as an acid stem (`ethanoic`, `propanoic`), then `anhydrideName`.

Completeness guard: account for ALL atoms of these groups (both acyl chains, bridging O, =O's, halogen, O-alkyl chain). If a side is not a simple expressible chain, DECLINE (round-trip discipline).

- [ ] **Step 1: Failing end-to-end tests** (`engine.tier2b.test.ts`), PubChem-checked corpus:
  `CC(=O)Cl`→ethanoyl chloride; `CCC(=O)Br`→propanoyl bromide; `ClC(=O)CCC(=O)Cl`→pentanedioyl dichloride; `CC(=O)OCC`→ethyl ethanoate; `CCC(=O)OC`→methyl propanoate; `CC(=O)OC(C)C`→propan-2-yl ethanoate; `C=CC(=O)OC`→methyl prop-2-enoate; `CC(=O)OC(=O)C`→ethanoic anhydride; `CC(=O)OC(=O)CC`→ethanoic propanoic anhydride. Also keep: ester+acid present → acid is PCG (ester demotes); a ring-containing ester → unsupported (Tier 3).
- [ ] **Step 2: Run, confirm fail.**
- [ ] **Step 3: Implement** routing + accounting. Cross-check each output against PubChem live; fix to the systematic PIN.
