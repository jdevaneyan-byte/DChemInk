## Algorithm (bicyclic von Baeyer)

A bridged bicyclic = two **bridgehead** atoms connected by **three bridges**. Bridge sizes a≥b≥c (atoms excluding bridgeheads); total ring atoms = a+b+c+2.
- Name: `bicyclo[a.b.c]<stem>` where stem = the chain stem for (a+b+c+2) carbons + `ane` (e.g. a+b+c+2=7 → heptane → bicyclo[2.2.1]heptane).
- **Numbering:** main bridgehead = 1; number along the LONGEST bridge (a) → 2…(a+1); second bridgehead = a+2; back along the SECOND bridge (b) → (a+3)…; then the SHORTEST bridge (c). Choose start bridgehead/direction to give lowest locants to (heteroatoms, then PCG, then substituents).
- **Heteroatoms (replacement "a" prefixes):** oxa/aza/thia + locant, e.g. `1-azabicyclo[2.2.2]octane` (quinuclidine), `1,4-diazabicyclo[2.2.2]octane` (DABCO), `oxabicyclo…`. Lowest locants to heteroatoms (O>S>N… per replacement priority).
- **Unsaturation/substituents/functional groups:** as usual, numbered per the von Baeyer numbering.

Tricyclic+ general algorithm (secondary bridges, superscript locants) is HARD — curate the common ones (adamantane = tricyclo[3.3.1.1³,⁷]decane, cubane, bicyclo… no) by table/fingerprint; DECLINE general tricyclic+.
