# P1.3 Tier 3 — Monocyclic rings · Design

Lifts the "rings → unsupported" gate for **single-ring** molecules. Same
architecture (engine ← `MolGraph` ← RDKit adapter; the adapter already records
`ringIds`/aromaticity). Builds on T1/T2/T2b: a ring can now be the parent, or a
substituent (`cyclohexyl`, `phenyl`) on a chain parent.

## Scope (T3 v1)

**In:** exactly ONE ring.
- **Carbocycles:** cycloalkanes / cycloalkenes: cyclopropane … cyclodecane,
  cyclohexene, cyclohexa-1,3-diene, etc.
- **Benzene** and substituted benzenes (methylbenzene, 1,2-dimethylbenzene, …).
- **Common monocyclic heterocycles** via a curated retained-name table with their
  fixed canonical numbering (see "Heterocycles" below): pyridine, furan,
  thiophene, pyrrole, imidazole, pyrazole, oxazole, thiazole, pyrimidine,
  pyrazine, pyridazine, pyran, and the saturated ones (pyrrolidine, piperidine,
  piperazine, morpholine, oxolane/tetrahydrofuran, oxane/tetrahydropyran,
  azetidine, oxirane, aziridine, …).
- Substituents on the ring (alkyl, halogens, the T2/T2b prefix groups).
- Functional groups on the ring → ring-parent suffixes (`-ol`, `-one`, `-amine`)
  and the **added-carbon** suffixes for groups whose carbon is *attached to* (not
  part of) the ring: `-carboxylic acid`, `-carbonitrile`, `-carbaldehyde`.
- Ring-vs-chain parent selection; ring as a substituent (`cyclohexyl`/`phenyl`/
  `pyridinyl`/…).
- A small **retained-name table** for mandatory IUPAC aromatic PINs (see below).

**Out (→ Tier 4, return `unsupported` with reason):** fused/bridged/spiro ring
systems (≥2 rings), heterocycles NOT in the curated table (general
Hantzsch–Widman / replacement nomenclature is deferred), ring assemblies
(biphenyl). Stereo → T5. Anything that fails the OPSIN round-trip → declined.

## Parent selection: ring vs chain

Per IUPAC 2013, when a molecule has both a ring and chains, the **parent must
contain the principal characteristic group (PCG)**; with that satisfied, a ring
is senior to a chain.

1. No PCG (hydrocarbon or prefix-only groups): **the ring is the parent**; chains
   become alkyl substituents. (e.g. `CCCC1CCCCC1` → butylcyclohexane.)
2. PCG present:
   - PCG on a ring atom (or its attached carbon) → **ring is parent**
     (cyclohexanol, cyclohexanone, benzoic acid, cyclohexanecarboxylic acid).
   - PCG only on a chain → **that chain is parent**, ring becomes a substituent
     (`C6H5-CH2-COOH` → 2-phenylacetic acid; `phenyl` prefix).

The existing chain machinery names chain parents and substituent chains; T3 adds
ring-parent naming and ring-as-substituent naming.

## Ring-parent naming

- **Cycloalkane:** `cyclo` + stem + `ane` (cyclohexane). Ring carbons numbered to
  give lowest locants to (PCG > unsaturation > substituents), same priority ladder
  as chains.
- **Cycloalkene/yne:** cyclohex-1-ene → "cyclohexene" (single, locant 1 omitted
  when unambiguous on the ring); multiple/again cite (cyclohexa-1,3-diene).
- **Benzene:** aromatic 6-membered all-carbon ring → `benzene`; substituents as
  prefixes (methylbenzene, 1,3-dimethylbenzene, (bromomethyl)benzene…).
- **Suffix groups on a ring carbon:** `-ol` (cyclohexanol), `-one`
  (cyclohexan-1-one / cyclohexanone), `-amine` (cyclohexan-1-amine). 'e'-elision
  as before.
- **Added-carbon groups** (carbon NOT in the ring, hanging off it):
  `-carboxylic acid` (cyclohexanecarboxylic acid), `-carbonitrile`
  (cyclohexanecarbonitrile), `-carbaldehyde` (cyclohexanecarbaldehyde). These
  replace `-oic acid`/`-nitrile`/`-al` when the group's carbon is exocyclic to the
  ring parent. (Seniority for choosing PCG is unchanged.)
- **Single substituent → no locant** (methylcyclohexane); **two or more → lowest
  locants** (1,2-dimethyl…, cite the suffix/PCG as locant 1 first).

## Retained aromatic names (mandatory IUPAC PINs — universal, authored by us)

A tiny table, applied when the benzene ring bears exactly the defining group:
`phenol` (–OH), `aniline` (–NH₂), `benzoic acid` (–COOH), `benzaldehyde` (–CHO),
`benzonitrile` (–CN), `toluene` (–CH₃), `styrene` (–CH=CH₂), `benzamide`
(–CONH₂). For multiply-substituted rings we fall back to systematic
(methylbenzene + locants) unless a retained parent is still valid (e.g.
4-chlorophenol keeps `phenol` as parent — retained names that permit
substitution). **Correctness gate: every emitted name must round-trip through
OPSIN to the input structure; if a retained form doesn't, emit the systematic
form (or decline).**

`cyclohexyl` / `phenyl` etc. are the ring-as-substituent prefix names.

## Heterocycles (curated table)

Identify the bare ring (ring atoms with substituents stripped to H) and match its
**canonical SMILES** (computed via RDKit) against a table mapping → `{ name,
numbering }`, where `numbering` fixes which ring atom is locant 1 and the
direction (heteroatom(s) lowest locants, per the retained-ring conventions). Each
entry stores the ring's canonical SMILES so matching is exact and structure-based
(not string-fragile).

Examples (aromatic): pyridine (`c1ccncc1`, N=1), pyrimidine (N at 1,3), pyrazine
(1,4), pyridazine (1,2), furan (O=1), thiophene (S=1), pyrrole (N=1), imidazole
(1,3 N), pyrazole (1,2 N), oxazole, thiazole. Saturated: piperidine, pyrrolidine,
piperazine, morpholine, oxolane (THF), oxane (THP), azetidine, oxirane, aziridine.

Substituents/functional groups are numbered from the table's fixed numbering,
choosing the direction that gives the PCG/substituents the lowest locants while
respecting the heteroatom locants. Substituent-position naming: e.g.
2-methylpyridine, pyridin-3-ol, pyridine-2-carboxylic acid, furan-2-carbaldehyde,
1-methylpyrrolidine. Ring-as-substituent: pyridin-2-yl, furan-3-yl, etc.

A heterocycle whose bare ring is NOT in the table → `unsupported`
("ring not yet supported — Tier 4"). The OPSIN round-trip is the final gate: any
emitted heterocycle name that doesn't parse back to the input is suppressed.

## Module changes

- **`ring.ts` (new):** perceive the single ring — atoms (cyclic order), bonds,
  aromaticity, ring size, ring heteroatoms; reject ≥2 rings → unsupported. Ring
  numbering (lowest-locants ladder for carbocycles; fixed table numbering for
  heterocycles). The curated heterocycle table (canonical-SMILES → name+numbering)
  and the retained-aromatic table live here. Helpers shared with the engine.
- **`functionalGroups.ts`:** carbonyl/etc. perception already works on ring atoms;
  add classification of whether a group's carbon is ring-internal vs added-carbon
  (drives `-one` vs `-carbaldehyde`, etc.).
- **`engine.ts`:** parent = ring or chain (selection above). New ring-parent path;
  ring-as-substituent path; route added-carbon suffixes. Completeness guard must
  cover ring atoms + ring substituents.
- **`assemble.ts`:** ring parent assembly (`cyclo…`, `benzene`, retained names),
  the `-carbo…` suffixes, ring substituent locants.
