# P1.3 Tier 2 — Functional groups + seniority · Design

Builds directly on Tier 1 (acyclic substitutive nomenclature). Same architecture
(pure-TS engine ← `MolGraph` ← RDKit adapter). Still **acyclic only** — rings are
Tier 3. Goal: name acyclic molecules that carry functional groups, matching
PubChem / ChemDraw on the supported classes.

## What's new conceptually

Tier 1 named a pure C/H skeleton. Tier 2 adds three intertwined rules:

1. **Functional-group perception.** Detect groups on the `MolGraph`: which atoms
   form a carboxylic acid, amide, nitrile, aldehyde, ketone, alcohol, amine, plus
   always-prefix groups (halogens, ether/alkoxy, nitro).
2. **Seniority → principal characteristic group (PCG).** When several group
   *types* are present, the single most-senior type is expressed as the **suffix**;
   every other group becomes a **prefix**. Seniority (IUPAC P-41 subset, high→low):
   carboxylic acid > ester > amide > nitrile > aldehyde > ketone > alcohol > amine.
   Groups with no suffix (halogens, alkoxy/ether, nitro) are **always prefixes**.
3. **Parent-chain & numbering rules change.** The principal chain must contain the
   greatest number of PCG occurrences (and the PCG-bearing carbon). Numbering
   assigns lowest locants in this priority order (P-31.1.4):
   **PCG (suffix) > skeletal multiple bonds (ene/yne) > detachable prefixes
   (alphabetical) > first-cited prefix alphabetically.**
   This slots *above* the Tier-1 ene/yne rule, which slots above substituents.

## Module changes

- **New `src/chem/naming/functionalGroups.ts`** — `perceiveGroups(graph): Group[]`,
  where `Group = { kind: GroupKind; carbon: number; atoms: number[] }` (`carbon` =
  the chain atom that bears the group, for locant assignment). Pure graph pattern
  matching, unit-tested with hand-built graphs.
- **`engine.ts`** — replace the "reject all heteroatoms" gate with: perceive
  groups; if any atom/group is outside the supported set (or a ring is present,
  or it's an unsupported element/charge), return `unsupported` with a reason.
  Pick the PCG by seniority. Pass PCG info into chain selection and assembly.
- **`chain.ts`** — chain selection/numbering gains a top-priority PCG-locant
  criterion (before the existing multiple-bond and substituent criteria), and the
  candidate chains are filtered to those containing the most PCG carbons.
- **`assemble.ts`** — append the suffix to the parent (with **'e'-elision**:
  drop the terminal `e` of -ane/-ene/-yne before a vowel-initial suffix, keep it
  before a consonant). Merge functional-group prefixes into the existing
  alphabetized prefix list. Handle multiplicative suffixes (-diol, -dione,
  -dioic acid, -dial, -diamine).
- **`adapter.ts`** — already emits element/charge/H-count/bond-order for O, N,
  halogens; likely no change. Verify O/N implicit-H counts populate `hydrogens`.

## Supported groups (Tier 2 v1)

**Suffix groups** (the PCG when most senior; prefix form when not):

| Group | Detect (on `MolGraph`) | Suffix | Prefix form | Example |
|---|---|---|---|---|
| Carboxylic acid | C with =O and –OH | `-oic acid` | carboxy- | ethanoic acid (`CC(=O)O`) |
| Amide (1°) | C with =O and –NH₂/–NH–/–N< | `-amide` | carbamoyl- | ethanamide (`CC(=O)N`) |
| Nitrile | C≡N | `-nitrile` | cyano- | ethanenitrile (`CC#N`) |
| Aldehyde | C with =O and ≥1 H (terminal) | `-al` | oxo- | propanal (`CCC=O`) |
| Ketone | C with =O, both other bonds to C | `-one` | oxo- | propan-2-one (`CC(=O)C`) |
| Alcohol | O with 1 H, single-bonded to C | `-ol` | hydroxy- | propan-2-ol (`CC(O)C`) |
| Amine | N single-bonded to C only | `-amine` | amino- | propan-2-amine (`CC(N)C`) |

**Always-prefix groups:**

| Group | Detect | Prefix |
|---|---|---|
| Fluoro/Chloro/Bromo/Iodo | F/Cl/Br/I on C | fluoro-/chloro-/bromo-/iodo- |
| Ether (alkoxy) | O single-bonded to two C | (R)oxy-, e.g. methoxy-, ethoxy- |
| Nitro | N(+)(=O)O(−) on C | nitro- |

**Multiplicity:** identical PCGs → `-diol`, `-diamine`, `-dione`, `-dial`,
`-dinitrile`, `-dioic acid` (with the `e`-retaining 'a' linker, e.g.
`butane-1,4-diol`, `hexanedioic acid`).

## 'e'-elision rule (in assembly)

Drop the terminal `e` of the parent (-ane/-ene/-yne) when the following suffix
begins with a vowel (`a, o, u, y`); keep it before a consonant:
- `butane` + `-2-ol` → `butan-2-ol` (drop e before 'o')
- `propane` + `-al` → `propanal`; + `-1-amine` → `propan-1-amine`
- `ethane` + `-nitrile` → `ethanenitrile` (keep e before 'n')
- `butane` + `-1,4-diol` → `butane-1,4-diol` (keep e before 'd')
- acids: `ethane` → `ethanoic acid`, `propane` → `propanoic acid`

## Explicitly OUT of scope for Tier 2 v1 (deferred)

- **Esters, anhydrides, acyl halides** — structurally two-part names
  (`ethyl ethanoate`); sequenced as a follow-up **T2b** after the single-suffix
  groups land. (Ester *is* in the seniority list, so it's planned, just last.)
- Rings / aromatics / heterocycles → Tier 3.
- Stereochemistry → Tier 5.
- Imines, thiols/sulfur groups, phosphorus groups, ethers-as-`oxa`, isocyanates,
  etc. → later tiers (return `unsupported` with a reason).

## Testing

- `functionalGroups.test.ts`: perception of each group on hand-built graphs +
  seniority selection (e.g. a molecule with both –OH and –COOH → PCG = acid,
  –OH becomes hydroxy- prefix).
- `assemble.test.ts`: suffix attachment + 'e'-elision + multiplicative suffixes.
- `engine.test.ts`: end-to-end SMILES→name corpus, cross-checked against PubChem,
  covering single groups, mixed groups (seniority), multiplicity, halogens,
  unsaturation + group interplay (e.g. `but-3-en-2-one`, `but-3-en-2-ol`).
- e2e: a few representative molecules show in the panel row.
- Regression: the full Tier-1 corpus must still pass unchanged.
