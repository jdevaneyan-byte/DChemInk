## Stage 0 (foundation, in `ring.ts`)

- `perceiveRingSystem(graph)`: all SSSR rings; classify the multi-ring system:
  two rings sharing exactly **2 atoms joined by a bond** → ortho-FUSED; sharing
  **1 atom** → SPIRO; sharing **2 atoms NOT bonded** (a bridge) → BRIDGED;
  sharing **>2 atoms** → ortho-and-peri-fused/bridged; disjoint rings →
  ASSEMBLY. Return `{ ringCount, kind: "mono"|"fused"|"spiro"|"bridged"|"other", atoms, bonds, aromaticAtoms }`.
- Route in engine: mono → existing T3/Stage-1 path; **fused → Stage-2 path**;
  spiro/bridged/other/assembly → `unsupported` with a specific reason (later stage).

## Stage 2 — curated fused table + isomorphism locant transfer

- **Polycyclic fingerprint** (pure-TS, generalize T3's single-ring fingerprint to
  the whole fused skeleton: per-atom (element, aromatic) + per-bond order,
  canonical under the ring system's automorphisms).
- **Curated table**: fingerprint → `{ name, canonicalAtomOrder }`, where
  `canonicalAtomOrder` lists the ring atoms in IUPAC-locant order (locant i =
  position i in the list). At name time, compute a graph isomorphism between the
  drawn ring system and the table entry to transfer locants onto the actual atoms
  (choose, among valid isomorphisms, the one giving lowest locants to PCG >
  substituents). If no table entry matches → `unsupported` ("fused ring system not
  yet supported — Tier 4 (general fusion)").
- **Systems to curate** (store skeleton + IUPAC numbering): naphthalene,
  azulene, indene, anthracene, phenanthrene; indole, isoindole, benzofuran,
  benzothiophene, benzimidazole, benzoxazole, benzothiazole, indazole,
  benzisoxazole, purine; quinoline, isoquinoline, quinoxaline, quinazoline,
  cinnoline, phthalazine, 1,8-/1,5-naphthyridine; 2H-chromene, 4H-chromene,
  isochromene, carbazole, acridine, pteridine, quinolizine. (Start with the most
  common ~12; add more as the audit demands.)
- **Substituents + functional groups**: numbered per the transferred locants,
  using the existing prefix/suffix machinery (methylnaphthalene → with locants;
  quinolin-?-ol; naphthalene-2-carboxylic acid; aminoquinoline; halonaphthalene).
- **Ring-as-substituent**: naphthalen-1-yl, naphthalen-2-yl, quinolin-3-yl, etc.
  (parent = chain when the PCG is on a chain off the fused ring).
- **Partially-hydrogenated** fused systems (indane, tetralin, indoline, chroman)
  and **fused-ring carbonyls** (quinolinone, isoindolinone) — attempt only if they
  round-trip; otherwise DECLINE (can extend later).
