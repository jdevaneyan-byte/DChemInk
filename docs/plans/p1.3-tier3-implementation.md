## Ring fingerprint (pure TS, used for heterocycle + benzene matching)

Given the ring atoms in cyclic order, build the canonical fingerprint: for every
rotation and both directions, form the tuple of per-atom `(element, aromatic)` and
per-bond `order`, and take the lexicographically smallest. Two rings match iff
their fingerprints (with substituents ignored — only ring atoms/bonds) are equal.
The heterocycle/aromatic table maps fingerprint → `{ parentName, locantOf(atom) }`
where `locantOf` assigns IUPAC locants to ring atoms (heteroatom(s) lowest), with
the chosen rotation/direction also minimising substituent locants.

## Task 2: Ring tables + numbering (`ring.ts`)

Add the data tables and a numbering function.

- **Carbocycle:** parent = `cyclo` + stem (cyclopropane … cyclodecane). Numbering by the existing lowest-locant ladder (PCG > unsaturation > substituents).
- **Retained aromatics** (benzene parent special-cases): `phenol` (–OH), `aniline` (–NH₂), `benzoic acid` (–COOH), `benzaldehyde` (–CHO), `benzonitrile` (–C≡N), `toluene` (–CH₃, monosubstituted only), `styrene` (–CH=CH₂), `benzamide` (–CONH₂). Otherwise benzene + systematic prefixes (methylbenzene, 1,2-dimethylbenzene). Retained parents that allow further substitution (phenol, aniline, benzoic acid, benzaldehyde) keep the retained parent with the defining group at locant 1 (e.g. 4-chlorophenol).
- **Heterocycle table:** fingerprint → `{ parentName, locant(atomIndexInRing) }`. Cover (aromatic) pyridine, pyrimidine, pyrazine, pyridazine, furan, thiophene, pyrrole, imidazole, pyrazole, oxazole, isoxazole, thiazole, pyran; (saturated) pyrrolidine, piperidine, piperazine, morpholine, oxolane, oxane, azetidine, aziridine, oxirane, thiolane, thiane. Numbering: heteroatom = 1 (O>S>N priority for "1" when several differ; for same, lowest-locants to the set), then direction minimising substituent/PCG locants.
- Ring-as-substituent names: cyclohexyl, phenyl, pyridin-2-yl, furan-3-yl, etc. (`<parent drop trailing 'e'>yl` with attachment locant; benzene→phenyl special).

```ts
export interface RingNaming {
  parent: string;                 // "cyclohexane" | "benzene" | "pyridine" | retained
  locantOf: Map<number, number>;  // ring atom index → IUPAC locant
  kind: "carbocycle" | "benzene" | "heterocycle";
  retainedAromatic?: string;      // when a retained benzene parent applies
}
export function nameRing(graph: MolGraph, ring: RingInfo, opts): RingNaming | null; // null → unsupported
```

## Task 3: Ring-parent assembly (`assemble.ts`)

Compose ring parent names with substituents, unsaturation (cycloalkene), and
suffixes — including the **added-carbon** suffixes.

```ts
// "-carboxylic acid" / "-carbonitrile" / "-carbaldehyde" for exocyclic group carbons
export type AddedCarbonSuffix = "carboxylic acid" | "carbonitrile" | "carbaldehyde";
export function assembleRingName(input: {
  parent: string;                  // from RingNaming
  subs: { locant: number; name: string }[];
  ringDoubleBondLocants?: number[];// cycloalkene/diene (carbocycle only)
  suffix?: SuffixSpec;             // -ol/-one/-amine on a ring atom
  addedCarbon?: { kind: AddedCarbonSuffix; locants: number[] };
  retainedAromatic?: string;       // phenol/aniline/etc. parent
}): string;
```
Rules: single ring substituent → no locant (methylcyclohexane); ≥2 → locants
(1,2-dimethylcyclohexane). `-ol/-one/-amine` 'e'-elision as before
(cyclohexanol, cyclohexan-1-one→cyclohexanone, cyclohexanamine). Added-carbon:
cyclohexanecarboxylic acid, cyclohexanecarbonitrile, cyclohexanecarbaldehyde,
benzene→benzoic acid (retained). Cycloalkene: cyclohexene (locant 1 omitted when
unique), cyclohexa-1,3-diene.

## Task 4: Engine routing — ring vs chain parent (`engine.ts`)

Replace the ring rejection with routing:
1. `perceiveRing` → null & there IS a ring (ringIds present / `hasHeavyAtomCycle`) → unsupported "fused/multiple rings — Tier 4". Heterocycle not in table → unsupported "ring not yet supported — Tier 4".
2. Determine PCG (existing seniority). **Parent = ring** when: no PCG, OR the PCG sits on a ring atom or its directly-attached exocyclic carbon (added-carbon groups). **Parent = chain** when the PCG is on a chain not involving the ring → ring becomes a substituent (`cyclohexyl`/`phenyl`/heteroaryl) named via Task 2's substituent form, attached at its locant; chain named by existing machinery.
3. Ring-parent path: collect ring substituents (alkyl chains via `nameSubstituent`, halogens, T2/T2b prefixes, ring-attached lower-priority groups) with their ring locants; cycloalkene double-bond locants; the PCG suffix (ring-atom `-ol/-one/-amine`, or added-carbon `-carbo…`). Call `assembleRingName`.
4. **Completeness guard** extended: account ring atoms + all ring substituents/groups. Off-ring complex substituents that aren't expressible → decline (round-trip discipline). Multiple-bond guard: ring (aromatic/cycloalkene) bonds are accounted; exocyclic stray multiple bonds still decline.
