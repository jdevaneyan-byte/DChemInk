# P1.3 Tier 2b — Acid derivatives (esters, acyl halides, anhydrides) · Design

The deferred acid-derivative groups from Tier 2. Same architecture (engine ←
`MolGraph` ← RDKit adapter), still **acyclic only**. These use **functional-class
/ two-part names** rather than the single-suffix machinery, so they get dedicated
assembly paths. Cross-checked against PubChem + the OPSIN round-trip audit.

Currently these all return `unsupported` ("…T2b"); this milestone makes them
named. The structural guards and completeness checks from Tier 2 stay in force.

## Seniority

IUPAC seniority of acid derivatives (high→low), slotting into the existing table:
**carboxylic acid > anhydride > ester > acyl halide > amide > nitrile > …**
When one of these is the most senior group present it becomes the principal
characteristic group and dictates the name form below; less-senior groups become
prefixes as usual.

## The three classes

### Acyl halide — `R-C(=O)-X` (X = F/Cl/Br/I)
Name: **`<acyl> halide`**, two words. The acyl group = the acid chain with
`-oyl` (drop "-ic acid"/"-oic acid" → "-oyl"): ethanoyl, propanoyl, butanoyl.
Halide word: fluoride / chloride / bromide / iodide.
- `CC(=O)Cl` → **ethanoyl chloride**
- `CCC(=O)Br` → **propanoyl bromide**
- diacyl dihalide (both ends): `ClC(=O)CCC(=O)Cl` → **pentanedioyl dichloride** (PubChem-checked).

### Ester — `R-C(=O)-O-R'`
Name: **`<R'-yl> <R-chain>oate`**, two words. The acyl side (R-C(=O)-) is named as
the acid → `-oate` (ethanoate, propanoate). The R' alkyl on the ester oxygen is
named as a substituent group (methyl, ethyl, propan-2-yl, …) and cited first.
- `CC(=O)OCC` → **ethyl ethanoate**
- `CCC(=O)OC` → **methyl propanoate**
- `CC(=O)OC(C)C` → **propan-2-yl ethanoate**

### Anhydride — `R-C(=O)-O-C(=O)-R'`
Name uses **`anhydride`**. Symmetric (R = R'): `<acid-stem>oic anhydride`.
Unsymmetrical: both acid stems, alphabetical, each as `…oic`, then `anhydride`.
- `CC(=O)OC(=O)C` → **ethanoic anhydride** (symmetric)
- `CC(=O)OC(=O)CC` → **ethanoic propanoic anhydride** (mixed, alphabetical).

## Module changes

- **`functionalGroups.ts`** — replace the three `unsupported` early-returns with
  real group kinds: `ester`, `acylHalide`, `anhydride`. Perception:
  - acyl halide: carbonyl C + single-bonded halogen (the existing detector site).
  - ester: carbonyl C + single-bonded O that bonds to another C (no H).
  - anhydride: an O single-bonded to **two** carbonyl carbons (C(=O)-O-C(=O)).
  Each group records its acyl carbon(s), the bridging O (ester/anhydride), the
  halogen (acyl halide), and the O-alkyl carbons (ester). Add to `SENIORITY`.
- **`engine.ts`** — when the PCG is one of these, branch to a dedicated namer
  (below) instead of the suffix path. The acyl/alkyl sub-chains are named with
  the existing chain machinery (`selectPrincipalChain`/substituent naming).
  Completeness guard must count the new groups' atoms (acyl C + chain, bridging
  O, halogen, O-alkyl chain).
- **`assemble.ts`** (or a new `assembleClass.ts`) — builders for the two-part
  forms: `acylHalideName`, `esterName`, `anhydrideName`. They compose existing
  parent-name pieces (stem + unsaturation) with the class-specific endings/words.

## Naming detail (acyclic v1)

- Acyl/acid chain: the carbonyl carbon is C1 of its chain (terminal). Unsaturation
  on that chain is expressed normally (e.g. `prop-2-enoyl chloride`,
  `prop-2-enoate`). 'e'-elision applies before `-oyl`/`-oate` (vowel 'o').
- Ester O-alkyl side: named with `nameSubstituent` (gives `methyl`, `ethyl`,
  `propan-2-yl`, `2-methylpropyl`, …). Complex O-alkyl gets parentheses per the
  existing rule.
- Multiplicity: diesters/dianhydrides and mixed cases beyond the examples above
  are v1-optional; if they don't round-trip cleanly, DECLINE rather than mis-name
  (the completeness/round-trip discipline from Tier 2).

## Out of scope (later)

Rings/cyclic anhydrides → Tier 3. Esters/anhydrides where an acyl or alkyl side
is itself ring-containing or carries another principal group → later. Thioesters,
phosphate esters, etc. → later. Anything that fails the OPSIN round-trip → declined.

## Testing

- `functionalGroups.test.ts`: perceive ester / acyl halide / anhydride; seniority
  (acid still beats them; they beat amide).
- `assemble`/engine tests: the worked examples above, each PubChem-cross-checked.
- Re-run the OPSIN round-trip **1000-example audit** (now including these classes,
  which previously inflated the "unsupported" bucket). Target: 100% match on named.
- Full Tier-1/Tier-2 regression must stay green.
