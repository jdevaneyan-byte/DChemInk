# P1.3 Tier 4 — Polycyclic + bridged + spiro + cyclic carbonyls · Design

Scope (user decision): **everything** — fused ring systems, von Baeyer bridged,
spiro, and cyclic carbonyls (lactams/lactones/pyridinones). Because full general
fusion/von-Baeyer/spiro nomenclature is one of the largest pieces of IUPAC, this
is built in **audited stages**. The no-wrong-names invariant holds throughout:
anything a stage can't name correctly is DECLINED (never mis-named), and each
stage passes BOTH audits (OPSIN round-trip for structure + PubChem name-string
for preferred name) before it's considered done.

Same architecture (engine ← `MolGraph` ← RDKit adapter). The prerequisite for
all of T4 is **multi-ring perception** (T3's `ring.ts` only handles a single
ring); that's Stage 0.

## Stages

### Stage 0 — Multi-ring perception + classification (foundation)
- Perceive ALL rings (SSSR) and classify the ring system: number of rings, and
  for each pair whether they share **2+ atoms via a bond** (fused/ortho),
  **1 atom** (spiro), or **2 atoms not bonded** (bridged), or are isolated
  (ring assembly / separate). Build a "ring-system fingerprint" (canonical,
  pure-TS) over the whole polycyclic skeleton for table lookup.
- Route: single ring → existing T3 path; multi-ring → the T4 paths below; can't
  classify / unsupported → decline with reason.

### Stage 1 — Cyclic carbonyls (lactams / lactones / pyridinones) [monocyclic]
- A tabled monocyclic heterocycle bearing a ring/exocyclic carbonyl → name as the
  heterocycle parent + `-one`/`-dione` with **indicated hydrogen** where required:
  pyridin-2(1H)-one, pyrimidine-2,4(1H,3H)-dione (uracil), oxolan-2-one
  (γ-butyrolactone), pyrrolidin-2-one, piperidin-2-one, azepan-2-one
  (caprolactam), 2H-pyran-2-one. Lifts the T3 "pyridinone → decline".
- Indicated-hydrogen computation is the hard part; OPSIN round-trip + PubChem
  gate it. Decline any indicated-H case that doesn't round-trip.

### Stage 2 — Curated fused ring systems (retained names)
- Curated table (ring-system fingerprint → `{ name, atom→locant }`) for common
  fused systems: naphthalene, anthracene, phenanthrene, azulene, indene, indane
  (2,3-dihydro-1H-indene), indole, isoindole, indoline, benzofuran,
  benzothiophene, benzimidazole, benzoxazole, benzothiazole, indazole, purine,
  quinoline, isoquinoline, quinoxaline, quinazoline, cinnoline, phthalazine,
  1,x-naphthyridine, chromene (2H-/4H-), isochromene, chromane, carbazole,
  acridine, pteridine, … with fixed IUPAC numbering. Substituents + functional
  groups + ring-as-substituent (naphthalen-2-yl, quinolin-3-yl, …).
- General fusion nomenclature (computing names for UN-tabled fused systems via
  base + attached components + orientation/numbering) is attempted only as a
  fallback and will mostly DECLINE in v1.

### Stage 3 — von Baeyer (bridged) — algorithmic
- Bicyclo[a.b.c]alkane / tricyclo… : find main ring (two largest bridges), main
  bridge, number from a bridgehead along the longest bridge first, etc. Common
  cases: bicyclo[2.2.1]heptane (norbornane), bicyclo[2.2.2]octane,
  bicyclo[1.1.1]pentane, adamantane (tricyclo[3.3.1.1³,⁷]decane). Implement
  bicyclic fully; higher polycyclic-bridged decline if not confidently correct.

### Stage 4 — spiro — algorithmic
- Monospiro: spiro[a.b]alkane (carbocyclic) and spiro hetero (e.g.
  1-oxaspiro…). Number around the smaller ring first starting next to the spiro
  atom. Dispiro later/decline.

### Stage 5 — general fusion (stretch)
- Attempt algorithmic fusion naming for ortho-fused 2-component systems not in
  the curated table; decline what can't be verified.

## Cross-cutting

- **Ring-system fingerprint** (pure-TS) generalizes T3's single-ring fingerprint
  to the whole polycyclic skeleton (atoms + bonds + aromaticity, canonical under
  automorphism) for curated-table lookup.
- **Numbering** for tabled systems is stored data (atom→locant); for von
  Baeyer/spiro it's algorithmic.
- **Parent selection** extends: ring system vs chain (ring system senior when it
  contains the PCG, per T3 logic); among rings, the senior ring system is parent.
- **Completeness + no-wrong-names guards** unchanged and strictly enforced; every
  stage declines its out-of-scope inputs.
- **Audits per stage:** OPSIN round-trip (≥1000 generated incl. the stage's motifs)
  AND a PubChem name-string sample; fix every preferred-name bug; 0 wrong names.

## Out of scope (later / decline)

Ring assemblies (biphenyl — naming as substituted), complex bridged polycyclics
beyond bicyclic confidence, dispiro/polyspiro, fully general fusion for arbitrary
systems, stereo (T5).

## Execution

Implement Stage 0 first (foundation), then Stages 1→4 each as its own
spec-let/plan + implementation + dual audit + commit, in that order (highest
value first). Stage 5 last / best-effort. Each stage updates the roadmap.
