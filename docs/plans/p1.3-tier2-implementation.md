## Scope

**In:** carboxylic acid, amide (1°/2°/3° → `-amide`), nitrile, aldehyde, ketone, alcohol, amine as **suffix** groups (seniority high→low in that order); halogens (F/Cl/Br/I), ether→alkoxy, nitro as **always-prefix** groups; multiplicity (`-diol`/`-dione`/`-dioic acid`/`-dial`/`-diamine`/`-dinitrile`).

**Out (return `unsupported` with a reason):** esters / anhydrides / acyl halides → reason mentions "T2b" (DEFERRED, must implement next milestone); rings → "Tier 3"; charged/ionic species (carboxylate, ammonium), isotopes, S/P groups, imines → later tiers.

## Task 1: Functional-group perception + seniority (`functionalGroups.ts`)

**Files:** Create `src/chem/naming/functionalGroups.ts`; Test `tests/chem/naming/functionalGroups.test.ts`.

**Perception (on `MolGraph`), classify each relevant atom ONCE by priority:**
- Carbonyl carbon (C with a double bond to O):
  - + a single-bonded O that **carries an H** → **acid** (anchor = that C).
  - + a single-bonded O that bonds to **another C** (no H) → **ESTER** → mark unsupported (`reason` = "esters arrive in T2b").
  - + a single-bonded O with no H and no other C (O⁻) → unsupported (charged).
  - + a single-bonded N → **amide** (anchor = C).
  - + at least one H on the carbon → **aldehyde** (anchor = C; must be chain-terminal).
  - else (other two bonds to C) → **ketone** (anchor = C).
- C with a **triple bond to N** → **nitrile** (anchor = that C; it counts in the chain).
- O atom, 1 H, single bond to exactly 1 C, not part of an acid → **alcohol** (anchor = the C).
- O atom, single-bonded to exactly 2 C → **ether** (anchor = the C on the longer side; the shorter side → alkoxy prefix).
- N atom with formal charge +, one =O and one O⁻ → **nitro** (anchor = the attached C).
- N atom, only single bonds to C (not amide N, not nitro, not nitrile) → **amine** (anchor = the C).
- F/Cl/Br/I bonded to C → **halide** (anchor = the C).

```ts
// src/chem/naming/functionalGroups.ts
import type { MolGraph } from "./graph";

export type GroupKind =
  | "acid" | "amide" | "nitrile" | "aldehyde" | "ketone" | "alcohol" | "amine"
  | "halide" | "ether" | "nitro";

export interface Group {
  kind: GroupKind;
  carbon: number;        // chain carbon that bears the group (for locant)
  atoms: number[];       // all atoms belonging to the group (excluded from chain except `carbon` & nitrile/acid/al C)
  detail?: string;       // e.g. halogen element "Cl", alkoxy stem "methoxy"
}

/** Suffix-eligible seniority, high→low. Prefix-only groups are 0 (never PCG). */
export const SENIORITY: Record<GroupKind, number> = {
  acid: 80, amide: 60, nitrile: 50, aldehyde: 40, ketone: 30, alcohol: 20, amine: 10,
  halide: 0, ether: 0, nitro: 0,
};

export interface Perception {
  groups: Group[];
  unsupported?: string;  // set when an out-of-scope group/feature is present
}

export function perceiveGroups(graph: MolGraph): Perception { /* see logic above */ }

/** The principal characteristic group kind (most senior present), or null. */
export function principalKind(groups: Group[]): GroupKind | null {
  const suffixable = groups.filter((g) => SENIORITY[g.kind] > 0);
  if (suffixable.length === 0) return null;
  return suffixable.reduce((a, b) => (SENIORITY[a.kind] >= SENIORITY[b.kind] ? a : b)).kind;
}
```

## Task 2: Suffix assembly + functional-group prefixes (`assemble.ts`)

Extend `AssemblyInput` with an optional principal-suffix spec; merge FG prefixes into the existing alphabetized substituent prefixes.

```ts
export type SuffixKind = "ol" | "al" | "one" | "amine" | "amide" | "nitrile" | "oic acid";
export interface SuffixSpec { kind: SuffixKind; locants: number[]; }  // locants ascending
export interface AssemblyInput {
  chainLen: number;
  doubles: number[];
  triples: number[];
  subs: { locant: number; name: string }[];  // detachable prefixes incl. FG prefixes
  suffix?: SuffixSpec;                        // principal characteristic group
}
```

**Suffix rules (cross-check each against PubChem):**
- Multiplicity word from `locants.length`: 1→"", 2→"di", 3→"tri".
- **Locant omission:** omit the locant for `al`, `oic acid`, `nitrile`, `amide` (anchored at chain termini); also omit for any suffix on a chain where the position is degenerate (e.g. 2-carbon `ethanamine`, single occurrence). **Cite** the locant for `ol`, `one`, `amine` when chainLen ≥ 3 and the position is not forced.
- **'e'-elision:** the parent ends in `-ane`/`-ene`/`-yne`. Drop the terminal `e` before a vowel-initial suffix (`ol`,`al`,`one`,`amine`,`oic acid` → o/a/o/a/o), KEEP it before a consonant-initial suffix (`nitrile`→ keep: `ethanenitrile`) and before a multiplicity `d` (`di…`): `butane-1,4-diol`, `hexanedioic acid`, `pentanedial`, `hexane-2,5-dione`.
- Examples (assert in tests, all verified vs PubChem):
  - `{chainLen:4, suffix:{kind:"ol", locants:[2]}}` → `butan-2-ol`
  - `{chainLen:3, suffix:{kind:"al", locants:[1]}}` → `propanal`
  - `{chainLen:3, suffix:{kind:"one", locants:[2]}}` → `propan-2-one`
  - `{chainLen:2, suffix:{kind:"amine", locants:[1]}}` → `ethanamine`
  - `{chainLen:2, suffix:{kind:"oic acid", locants:[1]}}` → `ethanoic acid`
  - `{chainLen:2, suffix:{kind:"nitrile", locants:[1]}}` → `ethanenitrile`
  - `{chainLen:4, suffix:{kind:"ol", locants:[1,4]}}` → `butane-1,4-diol`
  - `{chainLen:6, suffix:{kind:"oic acid", locants:[1,6]}}` → `hexanedioic acid`
  - with prefix + unsaturation: `{chainLen:4, doubles:[3], suffix:{kind:"one",locants:[2]}}` → `but-3-en-2-one`
  - prefix interplay: `{chainLen:3, subs:[{locant:1,name:"chloro"}], suffix:{kind:"ol",locants:[2]}}` → `1-chloropropan-2-ol`

## Task 3: PCG-aware chain selection + numbering (`chain.ts`)

- New `selectPrincipalChain(cg, opts?: { pcgCarbons?: number[] })`:
  candidate sort priority — (1) **most PCG anchor carbons on the chain**, (2) longest, (3) most multiple bonds, (4) Tier-1 tie-breaks. The chain MUST contain a PCG carbon when one exists.
- `orient(path, cg, pcgCarbons?)`: prepend a **PCG-locant** comparison ahead of the existing multiple-bond comparison: lower locants to the set of PCG-anchor positions on the chain.

```ts
/** PCG anchor locants on a directed path (ascending). */
function pcgLocants(path: number[], pcg: Set<number>): number[] {
  const locs: number[] = [];
  path.forEach((a, i) => { if (pcg.has(a)) locs.push(i + 1); });
  return locs.sort((x, y) => x - y);
}
```

## Task 4: Engine orchestration + end-to-end corpus (`engine.ts`)

Replace the "reject all heteroatoms" gate with perception-driven naming.

Flow:
1. Empty → `empty`. Multiple fragments / rings (via `ringIds` OR the Tier-1 `hasHeavyAtomCycle` backstop) / charged atoms → `unsupported` with reason.
2. `perceiveGroups(graph)`; if `unsupported` set (ester/etc.) → return it.
3. Any element outside {C,H,O,N,F,Cl,Br,I} → `unsupported`.
4. `principalKind` → the PCG. Collect PCG anchor carbons. Map kind → `SuffixKind`
   (`acid`→"oic acid", `amide`→"amide", `nitrile`→"nitrile", `aldehyde`→"al",
   `ketone`→"one", `alcohol`→"ol", `amine`→"amine"). If no suffixable group, name as a
   Tier-1 substituted skeleton with FG prefixes only (e.g. halides/ethers/nitro).
5. `selectPrincipalChain(cg, { pcgCarbons })`. Compute suffix locants = PCG positions
   on the chain. Compute ene/yne locants (Tier 1). Collect detachable prefixes:
   Tier-1 alkyl substituents PLUS non-principal groups in prefix form
   (`alcohol`→hydroxy, `ketone`/`aldehyde`→oxo, `amine`→amino, `acid`→carboxy when
   not on chain end, `halide`→fluoro/chloro/bromo/iodo, `ether`→{stem}oxy, `nitro`→nitro).
6. `assembleName({ chainLen, doubles, triples, subs, suffix })`.
